# Helsinki MOOC — Java Programming

This repository contains my solutions to the [University of Helsinki Java Programming MOOC](https://java-programming.mooc.fi/), a free online course equivalent to **10 ECTS credits** from the Department of Computer Science at the University of Helsinki.

## Course Structure

### Java Programming I
| Part | Topics Covered |
|------|---------------|
| Part 1 | Printing, Variables, Reading Input |
| Part 2 | Loops, Methods, Conditionals |
| Part 3 | Lists, Arrays, Strings |
| Part 4 | Object Oriented Programming, Classes |
| Part 5 | OOP continued, Interfaces |
| Part 6 | Objects on a list, Files |
| Part 7 | Algorithms, Large programs |

### Java Programming II
| Part | Topics Covered |
|------|---------------|
| Part 8 | HashMaps, Similarity of Objects |
| Part 9 | Inheritance, Interfaces |
| Part 10 | Handling collections as streams |
| Part 11 | Class diagrams, Packages, Exceptions |
| Part 12 | Type parameters, ArrayList, HashMap |
| Part 13 | Graphical user interfaces (JavaFX) |
| Part 14 | Data visualization, Larger applications |
